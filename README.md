 # 🎯 DigiTools - Premium Digital Asset Marketplace

DigiTools is a sleek, high-performance web application designed for users to browse and manage premium digital tools and software. Built with a focus on user experience and clean design, this platform allows users to explore various digital products, compare pricing, and manage their selections through an intuitive cart system.

## 📝 Project Overview
This project was developed as part of a mission to create a functional, responsive, and visually appealing e-commerce interface for digital assets. It features dynamic content rendering from JSON data, a seamless toggling system between products and the shopping cart, and real-time notifications for user actions.

## 🛠️ Tech Stack
- **Library:** React.js (Vite)
- **Styling:** Tailwind CSS & DaisyUI
- **State Management:** React Hooks (`useState`, `useEffect`)
- **Notifications:** React-Toastify
- **Icons:** Lucide-React / FontAwesome
- **Data Source:** Custom JSON API

## 🚀 Key Features

* **Dynamic Product Management:** Users can browse a curated list of digital tools with real-time "Add to Cart" functionality. The navbar automatically updates the item count, providing instant feedback.
* **Dual-View Interface:** A smart toggling system that allows users to switch between the 'Product Discovery' view and the 'Personalized Cart' without any page reloads, ensuring a fast and smooth experience.
* **Interactive Shopping Experience:** Includes a full-featured cart where users can review their selections, remove unwanted items with a single click, and clear the entire cart during checkout with automated total price calculation.
